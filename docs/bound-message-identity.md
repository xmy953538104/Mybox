Patch0012 checks the existing identity-provider owner, obtains the already-loaded host Context's ClassLoader and caches only the public currentLeaseV1 Method. It never caches a caller or lease. Nonempty scope uses a versioned provider call; absence retains the existing PID path, including PID0 rejection. The provider first requires the real current trusted microG query process. The server resolves the exact live lease, owner/consumer VM generations and sealed package generations, admission/permissions and publication incarnation. Closed, foreign, stale or unpublished bindings cannot provide identity. Returned identity comes from the captured consumer generation, not claimed UID/PID/package/WorkSource. An already authenticated queued message may finish after unbinding; later old-endpoint requests fail.

The endpoint is a delegable binding capability: intentionally passing it to another same-host guest delegates that binding's consumer identity. It does not recover every transaction's original Linux PID or provide kernel isolation between same-UID processes. Broad native Binder UID virtualization and arbitrary-service/callback identity remain separate work; this candidate grants no general GMS/system role. Host reflection entry names must remain stable; current builds do not enable shrinking.
