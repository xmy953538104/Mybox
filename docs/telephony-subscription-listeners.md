# Real subscription-change listeners

Play startup attempted `TelephonyRegistry.addOnSubscriptionsChangedListener` with the guest package and physical host UID, and the OS rejected that mismatch. Original GBox's registry hook registrations are retained in REA `ev_6629255da26ebf59653938be6959f68d6a280dfa11e46902970fad22d537973d`; its first-package attribution helper was recovered as complete Smali (`ev_63e038e86abd9c532599ec3ec216b0b4335689fcb41a29f898f21becf82e6e2a`, Java reconstruction failed). The listener exception was caught by Play; it is not established as the sole Activity startup failure.

Mylite adapts ordinary and opportunistic subscription registration and their removal. It validates the actual local caller and exact platform signature, maps only the bound guest/host attribution to the real host package/tag, and keeps the actual callback Binder and OS exceptions. Both ServiceManager and discovered framework static registry caches use the same local interface; raw transactions and foreign attribution are rejected. The API26/28/29 two-argument and API30+ feature-bearing registration shapes are checked against official AOSP interfaces.

The Android boundary tests cover callback identity, arguments, foreign/null packages, unknown shapes, cache identity and real exception propagation. The runtime test registers both public listener types, stimulates two actual OS notifications using test-only shell permission, observes callbacks, unregisters and checks later notifications no longer reach them. Per-run UUIDs and actual Activity-destruction acknowledgements prevent stale test sessions from satisfying a later run. New Android results are pending. A device without the real registry reports absence, not fabricated callback coverage. Sensitive radio events, identifiers and full telephony/device-profile compatibility remain separate unfinished work.
